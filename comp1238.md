## Week 1 - History
- Most modern keyboard keys originate from typewriters.
- Many computing terms and concepts come from WAY before computers were invented.

  ## Week 2 - Bits and Bytes
  - A bit can hold one of two possible values (0/1), bit is short for binary digit.
  - ASCII stands for American Standard Code for Information Interchange, it is a table of characters and control codes used to standardize communication.

 ## Week 3 - Markup
 - MarkDown is a very simple markup language that has became very popular, it is great for quick documentation.
 - JSON stands for JavaScript Object Notation, it is a newer text format used to serialize structured data (it is intended to be read by computer software but still can be human-readable).

 ## Week 4 - Typing
 - Keys like "ctrl", "shift", "alt", and "windows" and called modifier keys, they modify the normal action of another key.
 - the shift key got it's name from back when the shift key on a printer would shift the entire printer to line up capital letters and other alternative characters to be typed out rather than the normal characters.

## Week 5 - Command Prompt
- to help better understand a bunch of different commands on terminal, enter bandit0s SSH to start a fun hacking game where you use different commands to find passwords.
- SSH stands for secure shell and is encrypted unlike older options like telnet.
